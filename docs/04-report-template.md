# 报告模板

> 复制下面的模板直接用。方括号 `[]` 里是填写说明，交付前删掉。
>
> 也可以直接跑 `python tools/report_builder.py case.json -o REPORT.md` 自动生成。

| 指标 | 数值 |
|---|---|

## 七、行动建议

[按用户当前所处阶段给，不要给通用建议。]

**如果尚未参与**
1. 不参与。[理由]
2. [如果身边有人已经在推，怎么沟通]

**如果已投入且能提现**
1. **立即全额提现**，不要有"再赚一轮"的念头。
2. 到账后不再复投，不接受"推荐新人加速提现"之类的条件。
3. 保存充值记录、提现记录、制度页截图、群公告。

1. **停止一切追加投入**，包括"解冻金""保证金""税费""认证费"。
2. 保留全部证据：转账凭证、聊天记录、制度截图、群公告、APP 录屏。

4. 联合其他受害者统一报案，避免零散报案导致并案困难。

3. 保留原始证据，不要因为群解散就删除聊天记录。

## 填写要点

### 结论怎么写

**三段结构**：

1. **结构比对** —— "它的 X 与已判决的同类案件高度一致"
2. **背书证伪** —— "它宣称的 Y 在公开信息中无对应记录"
3. **核心问题** —— "不是会不会出问题，而是出问题后钱在哪里"

**不要写**：

- ❌ "这是个骗局"（越界定性）
- ❌ "一定会跑路"（无法证伪的预言）
- ❌ "大家千万别投"（情绪化，且不解决"已经投了怎么办"）

### 证据表怎么排

**按硬度排序，最硬的放前面**：

1. 官方文书（判决、通报、监管公告）
2. 政府系统数据（备案、工商、执行信息）
3. 平台自有页面（制度页、公告、客服话术）
4. 第三方公开数据（投诉、媒体报道）
5. 用户提供材料（转账记录、聊天截图）

**每行都要有来源和日期。** 没有来源的条目，删掉或降级到"未能核实项"。

### 评分表怎么填

只填**已核实并命中**的项。不要为了凑分把"疑似"写进去。

如果某一维度完全没有信息，写"信息不足"，不要写 0 分——
0 分会被读成"这一维度没问题"。

### 行动建议怎么写

**关键：按阶段分，不要给通用建议。**

"建议谨慎投资"是废话。用户要的是"我现在账上有 3 万提不出来，下一步干什么"。

参考 [`SKILL.md`](../SKILL.md) 第八节的阶段表和本文模板里的四类情况。

### 篇幅控制

| 类型 | 建议篇幅 |
|---|---|
| 快速筛查（只有一个项目名） | 800–1200 字 |
| 标准审查（有制度页 + 主体信息） | 2000–3000 字 |
| 深度审查（有判决比对 + 多轮取证） | 4000–6000 字 |

**宁短勿凑。** 证据不足时，1500 字的诚实报告比 5000 字的注水报告有价值得多。

## 排版建议

- 表格优先于长段落（证据、评分、时间线都用表格）
- 关键结论加粗，但**一段最多两处**
- 用 `>` 引用块放免责、提示、补充说明
- 不要用 emoji 装饰（评级用的 🔴🟠🟡🟢 除外）
- 数字带单位（"1.8%" 不是 "1.8"；"13.8%" 不是 "13.8"）
