# 一页纸速查清单

> 打印出来，查项目时逐项打勾。**5 分钟能查完的项标了 ⚡，优先做这些。**

---

## 0 · 三问快筛（30 秒）

```
□ 收益从哪来？       只能靠拉人 + 后来者的钱 → 🔴 停在这里，不用往下查
□ 收益率多少？       日化 > 1%（年化 37 倍+）→ 🔴 物理上不可能
□ 赚钱要拉人吗？     收益与下线数量挂钩 → 🔴 命中传销计酬
```

**三问有一个"是"，直接进入完整审查。三个都"否"但信息极少，标"信息不足"，不要硬评级。**

---

## A · 主体资质（25 分）

### ⚡ A1 备案主体（8 分）
- [ ] 去 [beian.miit.gov.cn](https://beian.miit.gov.cn/) 查域名备案
- [ ] 备案主体是：`企业` / `个体户` / `个人` / `无备案`
- [ ] **个人或无备案 → 记 8 分**

### A2 主体一致性（4 分）
- [ ] 备案公司名 = 宣传中的公司名？
- [ ] APP 里的运营方 = 备案主体？
- [ ] **对不上 → 记 4 分**

### ⚡ A3 实缴资本（5 分）
- [ ] 去 [gsxt.gov.cn](https://www.gsxt.gov.cn/) 查
- [ ] 注册资本：______ 万 ｜ 实缴：______ 万
- [ ] **实缴为 0 或 < 注册资本 10% → 记 5 分**
- [ ] 顺手看：社保人数 ______ 人（0 人 = 无真实团队）

### A4 工商状态（6 分）
- [ ] 经营状态：`存续` / `经营异常` / `注销` / `吊销`
- [ ] **异常/注销/吊销/地址失联 → 记 6 分**

### ⚡ A5 域名（6 分）
- [ ] WHOIS 查注册日期：______（距今 ______ 个月）
- [ ] 到期日期：______（距今 ______ 天）
- [ ] **注册 < 1 年 或 到期 < 180 天 → 记 6 分**
- [ ] 记录查询日期：______（WHOIS 每天在变）

---

## B · 收益结构（30 分）

### ⚡ B1/B2 收益率（12 / 6 分）
- [ ] 日化：______% ｜ 月化：______% ｜ 周期：______ 天
- [ ] 跑一次：`python tools/apr_calculator.py --daily X`
- [ ] **日化 ≥ 1% → 记 12 分｜0.1%–1% → 记 6 分**
- [ ] 周期自洽性：宣称 N 天回本 与 日化率 对得上吗？（对不上 = 制度拼凑）

### B3 拉人计酬（8 分）
- [ ] 直推奖：____% ｜ 间推：____% ｜ 团队奖：____%
- [ ] 有没有封顶？`有` / `无`
- [ ] **层级 ≥ 1 代且无封顶 → 记 8 分**
- [ ] 关键区分：赚的是**商品销售提成**，还是**新人入门费**？

### B4 门槛费（5 分）
- [ ] 参与是否需要先交钱？名义：____________
- [ ] **不交钱完全无法参与 → 记 5 分**
- [ ] 若为"购买产品包"：产品是否等值？能否单独购买？

### B5 锁仓复投（5 分）
- [ ] 本金锁仓 ______ 天
- [ ] 收益释放规则：____________
- [ ] **想拿钱必须先再给钱 → 记 5 分**

---

## C · 资金安全（25 分）

### ⚡ C1 提现规则（10 分）
- [ ] 能提现吗？`随时` / `限额` / `排队` / `不能`
- [ ] 手续费：______%
- [ ] 到账时间：______
- [ ] 有无附加条件：`邀请N人` / `补缴保证金` / `改积分` / `无`
- [ ] **任何形式的提现受限 → 记 10 分**
- [ ] 🚨 **"补缴保证金才能提现" = 二次收割，立即停止追加**

### ⚡ C2 收款方（6 分）
- [ ] 收款码是：`个人` / `对公` / `个体户`
- [ ] 收款方名称：____________
- [ ] **个人账户 → 记 6 分**

### C3 资金存管（5 分）
- [ ] 有无第三方存管？`有（合作方：______）` / `无` / `宣称有但查不到`
- [ ] **无存管 → 记 5 分**

### C4 造血能力（4 分）
- [ ] 宣称业务：____________
- [ ] 能找到真实营收证据吗？（店铺/物流/电费/交易流水）
- [ ] **找不到或明显无法覆盖承诺收益 → 记 4 分**
- [ ] 算一遍：真实年营收 ÷ 会员数 = 人均真实收益 vs 承诺收益

---

## D · 外部信号（20 分）

### D1 监管提示（8 分）
- [ ] 地方金融监管局 / 互金协会 / 公安 / 市场监管 有无提示？
- [ ] **有 → 记 8 分**

### D2 投诉（6 分）
- [ ] 黑猫投诉数量：______ 条
- [ ] 时间分布：集中在 ______
- [ ] 投诉内容：`提现不到账` / `要求补缴` / `客服态度` / `其他`
- [ ] **≥ 10 条且指向同一模式 → 记 6 分**

### D3 司法记录（6 分）
- [ ] 裁判文书网：______
- [ ] 执行信息公开网：______
- [ ] **有立案/判决/被执行 → 记 6 分**

### D4 官方撇清（4 分）
- [ ] 被宣称背书的机构有无否认声明？
- [ ] **有 → 记 4 分**

---

## 四刀（证据不全时用）

- [ ] **动机反推**：如果我是操盘手，什么时候跑最划算？→ 现在处于哪个阶段？
- [ ] **成本反推**：它省了哪笔不该省的钱？（域名/备案/场地/设计/客服）
- [ ] **对照法**：和已崩盘的同类盘比，制度结构重合度多少？
- [ ] **归谬法**：把它的核心话术推到底，会得出什么荒谬结论？

|---|---|---|

|---|---|

## 交付前最后四问

```
□ 每条结论都能追到公开来源吗？（不能的删掉或标"推断"）
□ 有没有写出"某某是骗子"这类定性？（有就改成风险描述）
□ 信息缺口都列出来了吗？（没查到的必须写"未能核实"）
□ 行动建议是按阶段给的吗？（未投/已投能提/已投不能提，三种情况不同）
```
