## 〇 · 心法

> **项目方的自我描述不算证据。唯一方向是：它为了支撑那个说法，花了多少钱、办了多少事。**

这句话的实操含义是：**把每一句宣称，翻译成一个成本。**

| 它宣称 | 翻译成成本 | 去哪验证 |
|---|---|---|
| "国资背景" | 需要工商股权登记里有国资股东 | 国家企业信用信息公示系统 |
| "技术团队来自硅谷" | 需要真实的研发投入（服务器、备案、APP 开发） | 域名年龄、备案主体、APP 包体 |
| "日化 1.8% 有实体支撑" | 需要真实营收 ≥ 承诺兑付 | 算账 + 找营收来源 |
| "在国家级会议中心开过招商会" | 场地租金（几万到几十万） | 场地可租，不能证明实力 |
| "注册资金 1000 万" | 实缴资本（认缴制下可以为 0） | 同一页面的"实缴"栏 |

**该花的钱没花 = 破绽。破绽串起来 = 结论。**

## 一 · 判定三要素

### 资金盘（庞氏结构）

三条同时成立：

```
① 拉人头赚推荐奖 —— 收益来自下线，不来自经营
② 收益率超过司法保护上限 —— 当前为一年期 LPR 的 4 倍（约 13.8%）
③ 项目方本身没有造血能力 —— 钱不产生钱，只在下线之间转移
```

### 传销型

在上述基础上再加：

```
① 注册需要门槛费 —— 不交钱就无法参与分配
② 以发展下线数量计酬 —— 团队计酬式，而非销售商品计酬
```

**法律依据**（详见 [`05-legal-mapping.md`](05-legal-mapping.md)）：

- 《禁止传销条例》第七条：三种传销行为类型
- 《刑法》第 224 条之一：组织、领导传销活动罪
- 《刑法》第 176 条：非法吸收公众存款罪
- 《刑法》第 192 条：集资诈骗罪
- 《关于办理组织领导传销活动刑事案件适用法律若干问题的意见》（2013）

> ⚠️ **本方法论只做特征比对，不做法律定性。** 三要素是"审查线索"，
> 不是"定罪标准"。最终认定权在司法机关。

### 为什么"先定性"很重要

不定性就直接列证据，会出现两个问题：

1. **证据没有挂靠点** —— "它域名快到期了"这句话，对资金盘是致命破绽，
   对一个刚上线的小创业公司只是正常现象。**必须先知道它属于哪一类，才知道哪些破绽致命。**
2. **结论会漂移** —— 写着写着从"这个项目有问题"变成"所有项目都有问题"，
   最后变成一篇情绪文，没有可用结论。

## 二 · A 维度：主体资质（25 分）

> **这一维度的特点是：全部可以在 10 分钟内查完，且几乎无法伪造。**

### A1 · 备案主体非企业（8 分）

**查什么**：网站域名有没有 ICP 备案？备案主体是个人还是企业？

**去哪查**：[工信部 ICP/IP 地址/域名信息备案管理系统](https://beian.miit.gov.cn/)

**怎么看**：

| 备案主体类型 | 说明 | 风险 |
|---|---|---|
| 企业（有限公司） | 正常 | 低 |
| 个体工商户 | 说明规模很小 | 中 |
| **个人** | 说明**没有企业主体在运营** | **高** |
| 无备案 | 境内服务器必须备案；无备案 = 服务器在境外或用 CDN 隐藏 | **高** |

**为什么这是破绽**：

一个宣称"集团化运营""注册资金千万"的项目，如果网站备案在个人名下，
那么**它连一个用于备案的公司主体都没有**。这不是"疏忽"，这是成本问题——
注册公司、对公账户、税务登记，全都要钱和时间。它省了这笔钱。

**常见规避手法**：

- 用境外服务器 + CDN（查不到备案）→ 这本身是破绽：**为什么不备案？**
- 用别的公司名义备案（"技术服务商"）→ 查备案主体与宣称主体的关系
- 用小程序 / APP 代替网站（不需要 ICP 备案）→ 转到 A3、A4 查工商

---

### A2 · 备案主体与宣称主体不一致（4 分）

**查什么**：备案的公司名，和它宣传里说的公司名，是不是同一个？

**怎么看**：把备案主体名称、宣传中的集团名称、APP 里的运营方名称，三者列出来对比。

**典型情况**：

```
宣传：「XX国际控股集团」
备案：某某网络科技有限公司（注册资本 10 万，注册地某县城）
APP：某某信息技术服务部（个体工商户）
```

三个名字，三个主体，互相之间**没有股权关系**。

**注意**：有股权关系 ≠ 没问题。但**没有股权关系**，说明"集团背景"是话术。

---

### A3 · 注册资本未实缴或实缴极低（5 分）

**查什么**：注册资本是多少？**实缴**是多少？

**去哪查**：[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)

**关键认知**：

> 中国实行**认缴制**。注册资本 1000 万，意味着股东"承诺"在某个期限内缴 1000 万，
> **不代表公司账户里真有 1000 万**。实缴才是真金白银。

**什么算破绽**：

- 实缴 0 元
- 实缴占注册资本 < 10%
- 实缴 ≤ 10 万元（一个宣称"集团"的主体，实缴十万）

**延伸查**：

- **年报**里的"资产总额""负债总额"——比注册资本可信得多
- **社保人数**——0 人 = 没有真实团队

**常见规避手法**：

- 频繁变更注册资本（先写 5000 万，出事前改成 100 万）
- 用香港/离岸公司做"集团"抬头（查不到实缴）

---

### A4 · 工商状态异常（6 分）

**查什么**：经营状态、经营异常名录、行政处罚、司法协助。

**什么算破绽**：

| 状态 | 含义 |
|---|---|
| 经营异常 | 未按时年报 / 地址无法联系 —— **最常见的前兆** |
| 注销 / 吊销 | 主体已不存在，但项目还在收钱 |
| 地址无法联系 | 人去楼空 |
| 已列入严重违法失信名单 | 惯犯 |

**特别提示**：

> **"经营异常"是资金盘最典型的早期信号之一。**
> 很多项目在崩盘前 1-3 个月，公司会先被列入经营异常（因为不去年报了），
> 但前端 APP 和社群还在正常运转。这个时间差，就是最后的逃生窗口。

---

### A5 · 域名新注册或即将到期（6 分）

**查什么**：WHOIS —— 注册时间、到期时间、注册商、注册人（多数已隐私保护）。

**什么算破绽**：

| 情况 | 含义 |
|---|---|
| 注册 < 1 年 | 新盘，还没经历完整周期 |
| 到期 < 180 天 | **准备跑** —— 跑路前不再续费是常见操作 |
| 一个主域派生无数二级域名轮换 | 被封一个换一个 |
| 注册商是廉价注册商 + 隐私保护 | 降低追踪成本 |

**为什么"快到期"是强信号**：

运营一个长期项目，续费域名是最便宜的动作（几十块一年）。
**连这个都不续，说明它没打算长期做。**

**注意时效**：WHOIS 信息每天在变，报告里必须写明查询日期。

## 三 · B 维度：收益结构（30 分）

> **这一维度权重最高，因为它直接决定"钱从哪来"这个根本问题。**

### B1 / B2 · 收益率（12 + 6 分）

**查什么**：日化、月化、年化、静态收益、动态收益。

**怎么算**：用 `tools/apr_calculator.py`。

```bash
python tools/apr_calculator.py --daily 1.8
```

**判定标准**：

| 日化 | 年化（复利） | 判定 | 分值 |
|---|---|---|---|
| ≥ 1% | ≥ 37 倍 | 无任何实体经营可支撑 | 12 |
| 0.3% – 1% | 2 – 37 倍 | 远超司法保护上限 | 12 |
| 0.1% – 0.3% | 44% – 2 倍 | 超出司法保护上限 | 6 |
| < 0.1% | < 44% | 需进一步核查收益来源 | 0 |

**关键认知**：

> **高收益本身不违法。** 违法的是"收益来源"和"计酬方式"。
>
> 但收益率有一个物理上限：**任何实体经营的年化回报，很难长期超过 30%。**
> 巴菲特 60 年的年化是 20% 左右。
>
> 当有人承诺年化 673 倍时，问题不是"能不能做到"，
> 而是"这个钱必须从谁的口袋里出"。

**周期自洽性检查**（工具会自动做）：

如果它宣称"7 天回本"，那隐含日化是 14.29%。
如果它同时宣称"日化 1.8%"，那么 7 天只能拿到 12.6%，回不了本。

**这两个数字对不上，说明制度说明本身是拼凑的** —— 这是很硬的破绽。

---

### B3 · 拉人计酬且无封顶（8 分）

**查什么**：推荐奖层级、计酬方式、有没有封顶。

**怎么看制度页**：

```
直推奖：8%
间推奖：5%
团队奖：3%（按团队业绩）
```

**判定**：

| 情况 | 判定 |
|---|---|
| 收益与"发展下线数量"或"下线业绩"挂钩 | 命中团队计酬 |
| 层级 ≥ 1 代且**无封顶** | 命中（8 分） |
| 有封顶（如"最多 3 代，且总奖励不超过 X"） | 减弱，但仍需看是否以拉人为主 |
| 收益只来自销售真实商品/服务 | 不命中 |

**为什么"无封顶"是关键**：

有封顶 = 平台控制了推广成本，说明它算过账。
无封顶 = 鼓励无限拉人，**推广成本最终由新会员承担**。

**注意区分**：

- **销售商品计酬**（卖货拿提成）—— 合法
- **发展人员计酬**（拉人拿提成）—— 《禁止传销条例》第七条第（三）项

区别在于：**你赚的钱，是来自商品销售，还是来自新加入者的入门费。**

---

### B4 · 存在入门门槛费（5 分）

**查什么**：参与需不需要先交钱？以什么名义？

**常见名义**：

- 会员费 / 激活费 / 认证费
- "必须购买指定产品包"（变相门槛费）
- "充值满 X 元才能开始收益"
- "购买矿机/节点/席位"

**判定**：

| 情况 | 判定 |
|---|---|
| 不交钱完全无法参与分配 | 命中（5 分） |
| 交钱只是"提高收益等级"，不交也能赚 | 减弱 |
| 交钱买的是**真实等值商品** | 不命中（但要看商品是否虚高定价） |

**《禁止传销条例》第七条第（二）项**：
"要求被发展人员交纳费用或者以认购商品等方式变相交纳费用，
取得加入或者发展其他人员加入的资格"—— 这就是门槛费的法律表述。

---

### B5 · 锁仓或释放需复投（5 分）

**查什么**：本金能不能随时取？收益怎么释放？

**常见设计**：

- 本金锁仓 30/90/180 天
- 收益按比例"释放"，剩余部分在账户里
- **想提高释放比例，必须再买币/再充值**
- 提现需要"消耗"平台币

**为什么这是破绽**：

正常投资产品，**赎回是你的权利**。
当赎回被设计成"需要再投入"时，它就不是投资产品，是**资金留存机制**。

**判定**：只要出现"想拿钱必须先再给钱"，直接命中。

## 四 · C 维度：资金安全（25 分）

> **这一维度回答一个问题：出事后，钱还在不在？**

### C1 · 提现受限（10 分）

**查什么**：提现规则、到账时间、手续费、是否有附加条件。

**破绽清单**：

| 表现 | 含义 |
|---|---|
| 提现需要"排队" | 资金池不够，按顺序兑付 |
| 每日限额 / 每月限额 | 控制流出速度 |
| 手续费畸高（30%+） | 变相阻止提现 |
| 只能提"收益"，不能提"本金" | 本金已被挪用 |
| 改成"积分""代金券""平台币" | 用无价值凭证置换真实债务 |
| 提现需"邀请 N 人" | 用拉新换兑付 |
| 提现需"补缴保证金/税费" | **二次收割，最危险** |

**这一项权重最高（10 分），因为它是唯一一个"已经发生的伤害"**——
其他项都是"可能会出事"，提现受限是"已经出事了"。

---

### C2 · 收款方为个人账户（6 分）

**查什么**：充值页的收款码、收款账户名称、转账记录里的收款方。

**什么算破绽**：

- 收款码是个人微信/支付宝
- 对公账户名称与平台主体不一致
- 收款方是"某某商贸""某某服务部"（个体户）
- 要求转账到"客服个人账户"

**为什么这是硬破绽**：

正常企业收款，一定走对公账户（税务、发票、审计都需要）。
**走个人账户只有一个理由：不想留下可追溯的企业资金流水。**

出事后的直接后果：**你转账的对象是一个自然人，不是一家公司，追索难度完全不同。**

---

### C3 · 无第三方资金存管（5 分）

**查什么**：资金是否由银行/持牌支付机构存管？

**怎么看**：

- 正规平台会明示"资金由 XX 银行存管"
- 资金存管意味着：平台**不能直接动用**你的钱
- 没有存管 = 钱进了平台自己的账户，它想怎么用就怎么用

**判定**：

| 情况 | 判定 |
|---|---|
| 明确无存管，资金进平台账户 | 命中（5 分） |
| 宣称有存管，但查不到存管协议/合作方 | 命中，且**虚假宣传** |
| 有真实存管协议可查 | 不命中 |

---

### C4 · 无真实造血业务（4 分）

**查什么**：它靠什么赚钱？这个赚钱方式能覆盖承诺的收益吗？

**逐项对账**：

| 宣称业务 | 要核实什么 |
|---|---|
| 跨境电商 | 有没有真实店铺？SKU 数量？物流单号？ |
| 矿机挖矿 | 矿场在哪？电费单？算力收益能否覆盖？ |
| 直播打赏 | 主播是谁？平台分成比例？ |
| 商城返利 | 商品价格是否虚高？返利资金来自商品利润还是新会员？ |
| 外汇/量化交易 | 牌照？托管银行？交易流水？ |

**核心算式**：

```
真实年营收 ÷ 会员总数 = 人均可分到的真实收益
人均真实收益 vs 承诺收益 = 缺口
```

缺口 > 0 且没有其他资金来源 → **缺口只能由新会员填** → 庞氏。

## 五 · D 维度：外部信号（20 分）

> **这一维度的作用是：有没有别人已经替你查过了。**

### D1 · 监管或官方已发风险提示（8 分）

**查什么**：

- 地方金融监督管理局风险提示
- 中国互联网金融协会风险提示
- 公安部 / 国家反诈中心通报
- 市场监管部门查处公告
- 微信公众平台违规处理公告

**为什么权重高**：官方提示是**已经过初步核查的结论**，可信度远高于自媒体。

---

### D2 · 投诉集中且指向同一模式（6 分）

**查什么**：

- 黑猫投诉：数量、时间分布、投诉内容
- 12315 平台
- 微博/贴吧/知乎的真实用户描述

**怎么看**：

| 特征 | 含义 |
|---|---|
| 投诉 ≥ 10 条 | 命中（6 分） |
| 投诉集中在近 1-2 个月 | 兑付刚出问题 |
| 投诉内容高度一致（"提现不到账"） | 系统性问题，不是个案 |
| 投诉内容分散（"客服态度差"） | 可能是服务问题，不是资金问题 |

**关键区分**：**投诉"提现不到账"和投诉"APP 卡顿"，是完全不同性质的信号。**

---

### D3 · 已有立案或司法记录（6 分）

**查什么**：

- 中国裁判文书网：项目方/关联公司的判决
- 中国执行信息公开网：被执行人、失信被执行人
- 检察院起诉书公开信息
- 公安通报

**为什么这是最硬的证据**：

判决书里有**已被法庭认定的事实**。这类材料可以直接引用，
不需要你再论证一遍。

**注意**：只引用**已生效**的判决，且注意区分"被告"与"受害人"。

---

### D4 · 官方已撇清关系（4 分）

**查什么**：被冒名的机构有没有发过声明？

**典型场景**：

- 项目宣称"某某国企战略合作" → 该国企发声明否认
- 项目宣称"某某明星代言" → 明星工作室发律师函
- 项目宣称"获某部委支持" → 该部委网站查无此事

**为什么这是破绽**：**官方撇清 = 项目方最核心的背书被证伪。**
这种声明一旦出现，通常意味着项目已经引起注意，进入倒计时。

## 六 · 四把推理刀

当证据不全时，用逻辑补位。

### 刀 1 · 动机反推

```
问：他要是一直开着就能一直捞，为什么现在跑？
推：捞不动了 / 有人醒悟 / 风头来了
⇒ 跑路时机本身就是风险信号

问：跑路之后他会怎么样？
推：换个名字，把系统换个皮，再把这帮人团起来，还能继续割几茬
```

**用途**：判断"现在处于哪个阶段"，以及"新盘和老盘是不是同一批人"。

### 刀 2 · 成本反推

```
真项目方：招商会 + 宣发 + 网站 + 合规 + 客服，都是花钱堆的
小盘子：  啥也没有，啥也不是
```

**用途**：找出"省了哪笔不该省的钱"。域名、备案、设计、场地、服务器、证书——
每一项的缺失都是一个独立的破绽。

### 刀 3 · 对照法

| 对照对象 | 怎么比 |
|---|---|
| 公开渠道 | 商品拿去淘宝/京东比价 |
| 历史同类盘 | 制度结构是否与已崩盘项目一致 |
| 已判决案例 | 与判决书里描述的结构逐项比对 |
| 常识 | 138 块卡钱分给 3800 个景区？一算就崩 |

**用途**：在"这个项目本身查不出问题"时，用**结构相似性**判断。

### 刀 4 · 归谬法

把对方的逻辑推到底，让它自己崩塌。

```
"赚钱的事，人家和你素未谋面的，为啥要喊上你？？？"
"他们为什么不开 100 个小号去赚钱？？？"
"自己既当裁判，又当球员，我问你：你想赚钱？？？可能嘛？？？"
```

**用途**：在报告里做"结论段"的点睛，也用于和当事人沟通时打破认知闭环。

> **注意**：归谬法适合说服人，不适合写进证据表。
> 证据表只放可核查的事实。

## 七 · 骗局类型速查

| 类型 | 核心特征 | 最优先查 |
|---|---|---|
| **资金盘 / 互助盘** | 静态收益 + 动态拉人 + 强制复投 | B3 拉人计酬、B5 锁仓 |
| **山寨交易所** | 无牌照、后台控盘、提现设限 | A1 备案、C1 提现、C3 存管 |
| **数藏 / 数字藏品** | 平台自买自卖抬价、承诺回购 | B3 计酬、C1 提现、D1 监管 |
| **抢单 / 抢拍盘** | 排队抢单、强制复投、静态+动态 | B4 门槛费、B5 锁仓 |
| **分红返利盘** | 消费返利、按日分红 | C4 造血能力、B1 收益率 |
| **杀猪盘** | 先小赚后大亏、诱导加杠杆、出金要保证金 | C1 提现、C2 个人收款 |
| **套牌盘** | 冒用正规机构名义、高仿官网 | D4 官方撇清、A2 主体不符 |
| **传销（团队计酬）** | 门槛费 + 多层级 + 团队计酬 | B3、B4、《禁止传销条例》比对 |
| **云矿机** | 卖算力、承诺固定日收益 | C4 造血、B1 收益率 |
| **AI / RWA 概念盘** | 蹭新技术概念、无实际产品 | C4 造血、A 维度全查 |

## 八 · 结局套路链

绝大多数盘的走向高度一致，按时间顺序：

```
① 维稳（安抚别报警，"系统升级中"）
② 拖延提现（排队、限额、审核）
③ 改成代金券 / 积分 / 平台币
④ "重启"（发布重启方案，要求再投入）
⑤ 换币换皮（换名字、换制度、换 APP）
⑥ 停盘"系统维护"（长期维护公告）
⑦ 关网跑路（域名过期、客服失联、群解散）
⑧ 开新盘再割（同一批人，新名字，老会员可"平移"）
```

### 各阶段的最优动作

| 当前阶段 | 最优动作 |
|---|---|
| **未参与** | 不参与。任何"高收益 + 拉人计酬"的项目，只有"什么时候崩"，没有"会不会崩" |
| **提现正常** | **立即全额提现**。不要有"再赚一轮"的念头——绝大多数亏损发生在这个念头之后 |
| **提现变慢/限额** | 停止追加，保留全部证据，向属地公安经侦报案 |
| **要求再充值解冻** | **一分钱都不要再打**。这是二次收割，打进去不会解锁任何东西 |
| **群解散/客服失联** | 立即报案，联合其他受害者，固定证据，警惕换皮新盘 |
| **已换皮新盘** | 新盘同样不能碰。新旧制度页/域名/收款账户的对照，是同一操盘方的线索 |

## 九 · 常见规避手法

项目方会针对上面每一条设计规避动作。识别这些规避动作本身，就是最强的破绽证据。

| 你查什么 | 它怎么规避 | 规避动作本身就是破绽 |
|---|---|---|
| 备案主体 | 用境外服务器 + CDN | 为什么不备案？境内经营必须备案 |
| 实缴资本 | 频繁变更注册资本 | 出事前突击减资 = 预谋 |
| 域名到期 | 不断换新域名 | 换域名 = 被封过，或准备跑 |
| 源码比对 | 加密/混淆前端 | 正常网站不需要隐藏源码 |
| 拉人计酬 | 改叫"分享奖励""推广补贴" | 看钱从哪来，不看叫什么 |
| 门槛费 | 改叫"购买产品包" | 产品是否等值？能否单独购买？ |
| 提现限制 | 改叫"风控审核""合规检查" | 为什么只有提现要审核，充值不用？ |
| 个人收款 | 频繁更换收款码 | 为什么不敢用对公账户？ |
| 造血能力 | 展示"合作意向书""战略协议" | 意向书不是收入 |
| 监管提示 | 声称"已通过合规审查" | 要求出示具体文件编号 |

**核心逻辑**：

> **每一个规避动作，都在回答"它为什么不敢让你查"。**
> 而这个"为什么"，就是报告里最有价值的那句话。

## 附 · 一次完整审查的时间分配

| 阶段 | 耗时 | 做什么 |
|---|---|---|
| 收料 + 填事实卡 | 5 分钟 | 把已知信息和未知信息分开 |
| 快筛三问 | 3 分钟 | 判断值不值得深查 |
| A 维度（主体） | 10 分钟 | 备案 + 工商 + WHOIS |
| B 维度（制度） | 10 分钟 | 读制度页 + 算收益 + 看层级 |
| C 维度（资金） | 10 分钟 | 提现规则 + 收款方式 + 造血业务 |
| D 维度（外部） | 10 分钟 | 搜索 + 投诉 + 监管 + 判决 |
| 四刀 + 评分 | 10 分钟 | 逻辑穿透 + 跑工具 |
| 写报告 | 20 分钟 | 证据表 + 结论 + 建议 |
| **合计** | **约 80 分钟** | 其中 40 分钟是可并行的信息检索 |

**如果只有 15 分钟**：只做 A1（备案）、A3（实缴）、B1（算收益）、C1（提现规则）、C2（收款方）。
这五项能覆盖 41 分，且全部可在公开渠道查到。
