## 一、导入运行

**1. 下载开发者工具**

https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

选「稳定版 Stable Build」。

**2. 导入项目**

打开工具 → 导入项目 → 目录选本文件夹 `miniprogram/`。

**3. 填 AppID**

- **没有 AppID**：点「测试号」，可以直接在电脑上跑，不能真机预览、不能上传。
- **有 AppID**：填进去。AppID 在 [微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → 开发设置。

> `project.config.json` 里的 `"appid": "touristappid"` 是游客模式占位，导入时工具会让你重新填。

**4. 编译**

点「编译」，左侧模拟器就能看到界面。

### 第 1 步 · 注册小程序（免费）

https://mp.weixin.qq.com/wxopen/waregister → 选「小程序」

**主体类型必须选「个人」**，别选企业。个人主体不需要营业执照。

需要：一个**没有注册过公众号/小程序的邮箱** + 身份证 + 微信扫码验证。

### 第 2 步 · 填基本信息

| 字段 | 建议填法 |
|---|---|
| 名称 | 金融防骗预警 / 投资项目风险查询（名称唯一，可能被占用，多备几个） |
| 头像 | 深蓝底 + 金色几何图形，别用真人照 |

| 服务类目 | **工具 → 信息查询**（关键，见下方说明） |

### ⚠️ 类目是最大的坑

**绝对不要选「金融业」相关类目。** 金融类目要牌照：

| 金融类目 | 需要的资质 |
|---|---|
| 金融业-借贷 | 网络小贷牌照 / 地方金融办批文 |
| 金融业-证券/基金 | 证监会牌照 |
| 金融业-保险 | 保险中介牌照 |

个人主体**一样都拿不到**，选了直接被拒。

**正确做法**：选「**工具 → 信息查询**」。
把产品定位成「**信息查询工具**」，不是「金融顾问」。

文案上要避开：
- ❌ 投资建议、荐股、理财规划、收益预测
- ❌ 帮您判断项目是否违法（越界定性）
- ✅ 风险特征自查、公开信息查询、防骗知识科普

### 第 3 步 · 备案（免费，但必须）

2023 年 9 月起，所有小程序必须完成备案才能上线。

入口：小程序后台 → 设置 → 基本设置 → 小程序备案。

需要：主体信息、负责人信息、小程序服务内容说明。审核约 **1–2 周**。

**没备案 = 不能发布。**

### 第 4 步 · 提交审核

后台 → 版本管理 → 开发版本 → 提交审核。

审核重点看三件事：
1. 类目和内容是否匹配
2. 有没有诱导分享、诱导关注
3. 有没有违规收集个人信息

本项目**不收集任何用户数据**，所有计算在本地完成，这一项没问题。

## 五、数据怎么更新

当前版本是**纯前端 + 内置数据**：2259 条名单、18 个已判决案例、14 类模式全部打包在 `data/` 里（约 348KB，主包上限 2MB）。

好处：离线可用、零服务器、审核不需要配置「服务器域名」白名单。
代价：数据是快照，**名单更新要重新生成 + 重新发版审核**。

**更新步骤**（网站那边改完 `risk-list.js` / `cases.js` / `patterns.js` 之后）：

```bash
cd query-site
node tools/gen-miniprogram-data.js
```

输出会直接覆盖 `miniprogram/data/*.js`，然后重新上传发版即可。

如果以后想改成实时更新，再按原方案接 Supabase（需配置服务器域名白名单 + HTTPS + 鉴权）。

## 七、已知限制

- **tabBar 无图标**：当前用纯文字 tab，若要图标，在 `app.json` 的 tabBar 每项加 `iconPath` / `selectedIconPath`（81×81px PNG）。
- **环形评分图未实现**：小程序对 `conic-gradient` 支持不稳定，当前用大号数字 + 横向进度条替代。
- **数据是快照**：名单更新需重新生成 + 重新发版，不会自动同步。
- **项目库未做 A–Z 拼音分组**：网站有首字母索引，小程序简化为「状态筛选 + 模式筛选 + 搜索」，因为小程序对 `Intl.Collator` 支持不稳定。
- **项目库详情用弹窗**：点击条目弹出 `wx.showModal`，没有做独立详情页；如需要可加 `pages/detail`。
